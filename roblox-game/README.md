# Sky Bakery Tycoon (Roblox)

Een eerlijke tycoon-game voor Roblox: bouw een bakkerij op een zwevend eiland in de lucht.
Werkt op telefoon, tablet en pc. Alles in de winkel heeft een vaste inhoud: er zijn geen
lootboxen, geen betaalde eieren en geen gacha (veilig voor België en Nederland).

Snelle opdrachten (in deze map):
```
rokit install                          # tools installeren (eenmalig)
rojo serve                             # live verbinden met Roblox Studio
lune run tests/run                     # automatische tests
rojo build -o build/SkyBakeryTycoon.rbxl
lune run tests/place_check             # controleert het gebouwde bestand
lune run tools/new-update 1.1.0        # nieuwe update klaarzetten
```

Wat te koop is (alles optioneel, de game is gratis volledig speelbaar):
- **Game passes:** Auto Collect (99), Pastry Wardrobe (149), 2x Cash Forever (199), VIP Baker (249)
- **Developer products:** geld (15/49/99), 2x boost 15/60 min (29/79), losse hoeden, trails en thema's (35 tot 89)
- **Gratis:** hoeden, trails en thema's met sterren (verdien je met rebirth en events)
- **Private servers:** in te stellen op create.roblox.com
